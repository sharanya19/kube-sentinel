# Kube-Sentinel

## Overview
Kube-Sentinel (see [`README.md`](./README.md), [`requirements.txt`](./requirements.txt), and [`.env.example`](./.env.example)) is an AI Site Reliability Engineering (SRE) investigation and human-approved Kubernetes remediation subsystem targeting Google Cloud's Online Boutique (`microservices-demo` `v0.10.7`) in the `default` Kubernetes namespace. It groups cluster bootstrap scripts (`scripts/`), an in-cluster Prometheus/Alertmanager/Grafana/Loki/Alloy observability and fast-alerting stack (`monitoring/`), a deterministic chaos fault-injection and rollback harness (`chaos/`), a Model Context Protocol server separating always-on read-only triage tools from opt-in remediation actions (`mcp_server/`), a LangGraph + Google Gemini root-cause investigation agent and Alertmanager pull watcher (`agent/`), and a localhost-only FastAPI human-in-the-loop approval console (`ui/` and `ui/static/`). Runtime incident JSON artifacts are persisted to `reports/` (`KUBE_SENTINEL_REPORTS_DIR`), while `docs/` and `runbooks/` currently hold non-code documentation placeholders.

## Subdirectories & Boundaries
- `agent`: [`./agent/EGM.md`](./agent/EGM.md) - Read-only LangGraph + Google Gemini SRE investigation pipeline (`run_investigation`, `build_graph`, `investigate`), sequential Gemini quota-failover pool (`ModelPool`), MCP 2.x stdio adapter (`mcp_tools(read_only=True)`), Alertmanager pull watcher with fingerprint deduplication and 45s settle coalescing (`agent.watch`), and structured Pydantic `Report` / `SuggestedFix` synthesis (`status = "pending_approval"`).
- `mcp_server`: [`./mcp_server/EGM.md`](./mcp_server/EGM.md) - Model Context Protocol server (`MCPServer("kube-sentinel")`) exposing 15 always-on read-only Kubernetes, Prometheus, Alertmanager, and Loki triage tools (reaching in-cluster monitoring endpoints via the Kubernetes API service proxy without port-forwards) plus 3 opt-in deployment remediation tools (`scale_deployment`, `rollout_restart`, `rollout_undo`) gated behind `KUBE_SENTINEL_ALLOW_ACTIONS` and namespace/replica guardrails.
- `ui`: [`./ui/EGM.md`](./ui/EGM.md) (frontend child contract: [`./ui/static/EGM.md`](./ui/static/EGM.md)) - Localhost-bound (`127.0.0.1`) FastAPI human-in-the-loop approval backend, thread-safe `reports/<report_id>.json` store (`store.py`), background investigation/watch task runner (`server.py`), dry-run previewer and sole cluster-mutating MCP action caller (`fixer.call_action` with `KUBE_SENTINEL_ALLOW_ACTIONS="true"`), and 240s post-fix Kubernetes health verifier (`fixer.verify`), served with a zero-build JavaScript SPA (`ui/static/`).
- `monitoring`: [`./monitoring/EGM.md`](./monitoring/EGM.md) - Helm/kubectl installer (`install.sh`) and values/rule manifests deploying `kube-prometheus-stack` (`93.2.0`), Monolithic `Loki` (`21.2.1`) with local TSDB and Alertmanager v2 ruler forwarding, and `Grafana Alloy` (`1.15.0`) into namespace `monitoring`, alongside 5 Prometheus metric rules (`alert-rules.yaml`) and 1 LogQL error-rate rule (`loki-rules.yaml`) monitoring namespace `default`.
- `chaos`: [`./chaos/EGM.md`](./chaos/EGM.md) - Deterministic fault-injection and snapshot-backed restoration CLI (`chaos.py`) defining 5 single-root-cause Online Boutique failure scenarios (`redis-down`, `bad-config`, `oom-kill`, `bad-image`, `bad-probe`) with frozen `GroundTruth` evaluation specs (`scenarios.py`), single-active-scenario locking (`chaos/.state/`), and post-restore `0`-replica `ReplicaSet` cleanup (`delete_broken_replicasets`).
- `scripts`: [`./scripts/EGM.md`](./scripts/EGM.md) - Cross-platform Bash (`setup.sh`) and PowerShell (`setup.ps1`) bootstrap scripts applying upstream Online Boutique `v0.10.7` release manifests into the active `kubectl` namespace and waiting up to `600s` for deployment availability.
- `docs` (non-code placeholder): [`./docs/README.md`](./docs/README.md) - Unpopulated documentation placeholder for architecture diagrams, screenshots, and demo GIF (*status: not started yet*; pruned from EGM contract generation).
- `runbooks` (non-code placeholder): [`./runbooks/README.md`](./runbooks/README.md) - Unpopulated placeholder for Markdown failure remediation guides intended for future RAG indexing (*status: not started yet*; no vector DB or RAG search tool is wired into `agent/` or `mcp_server/` yet).
